# CA-STNER sample

`sample.jsonl` contains five human-verified annotation records: one each for
Kazakh, Kyrgyz, Tajik, Turkmen, and Uzbek.

This lightweight sample contains annotation metadata only. Audio files are not
redistributed here. The retained audio paths show the layout expected by the
complete dataset.

Validate the sample from the repository root:

```bash
python scripts/verify_release.py
```
